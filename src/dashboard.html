LANGKAH 3 · AKTIFKAN

Aktifkan di AI agent

Centang skill dan MCP untuk tiap AI agent. SantriHub hanya mengubah file buatannya sendiri.

Cara pakai halaman ini
  1. Centang di tabel: satu skill atau MCP untuk satu agent. Centang baris paket untuk semua isinya sekaligus.
  2. SantriHub Gateway: satu MCP “santrihub” di agent, isinya MCP pilihan Anda. Ganti isi tanpa mengubah config agent.
  3. Profil: simpan set skill + MCP dari satu agent, lalu terapkan ke agent lain sekali klik.

Upload Skill ke Gemini
  1. Setujui aturan distribusi, pilih Skill, lalu unduh paket.
  2. Buka Gemini melalui ekstensi. Jika bantuan otomatis gagal, buka Settings → Skills.
  3. Pilih Upload, lalu ZIP atau folder dengan SKILL.md di root sesuai opsi Gemini.
  4. Periksa isi dan tekan Create/Upload terakhir sendiri.

Deteksi halaman bukan bukti Skill aktif. Status konfirmasi member dicatat terpisah.

Peringatan distribusi

Dilarang membagikan, menjual ulang, mengunggah ulang, atau memberikan Skills, file, package, prompt, maupun materi resmi Santriverse kepada orang lain. Jika pelanggaran terbukti, member dapat dikeluarkan dari grup dan komunitas serta kehilangan pembaruan akses Skills.

Salinan yang sudah diunduh dapat disalin secara teknis; peringatan bukan DRM.

    MEMERIKSA
    Target kustom aktif

    Path tetap harus ditempel lengkap; browser tidak memberikan path absolut.

    Global semua workspace: ~/.gemini/config/skills/<id>/SKILL.md dan ~/.gemini/config/mcp_config.json. Project saat ini: <project>/.agents/skills/<id>/SKILL.md dan <project>/.agents/mcp_config.json. Jangan gunakan folder builtin, plugin, runtime, atau cache.

    !Tutorial konfigurasi manualJika auto-deteksi tidak menemukan target
    1. Antigravity Settings → Customizations → Installed MCP Servers → Manage MCP Servers → View raw config.
    2. Root JSON wajib memiliki objek mcpServers. Backup sebelum edit.
    {
  "mcpServers": {
    "santri-skills": {
      "command": "npx",
      "args": ["-y", "santriverse-skills", "mcp-serve"]
    }
  }
}

    Peringatan: jaga JSON valid dan jangan hapus server lain.

    Restart Antigravity?

    Simpan pekerjaan terlebih dahulu. Antigravity akan diminta tutup secara graceful lalu dibuka lagi. Pekerjaan belum disimpan dapat hilang.

    Memeriksa file dan konfigurasi global…

    Target global · semua workspace

    Bridge MCP santri-skills wajib terpasang pada scope global sebelum tes callback.

    Buktikan Antigravity benar-benar memuat skill: SantriHub menaruh kode baru di skill santrihub-cek, lalu agent mengirim kode itu balik lewat MCP.

    1. Siapkan kode cekMembuat skill santrihub-cek berisi kode baru, berlaku 10 menit.
    2. Restart AntigravitySkill dibaca saat sesi baru dimulai. Simpan pekerjaan Anda dulu.

    3. Tempel di chat Agent baruBuka chat Agent baru di Antigravity, tempel kalimat ini, lalu kirim.
      Gunakan skill santrihub-cek untuk mengecek SantriHub.
    MCP santri-skills menungguSkill dimuat menunggu

    Belum ada callback.

    Apa yang dibuktikan?

    Kode hanya ada di file skill santrihub-cek dan berganti setiap cek. Kalau agent bisa mengirimnya balik, agent itu memuat skill dari folder global di sesi ini. Daftar skill yang disebut agent adalah laporan agent, bukan bukti per file.

    Callback tanpa kode hanya membuktikan bridge MCP santri-skills berjalan; identitas client tidak diautentikasi. Untuk tes MCP saja, panggil tool santrihub_status di chat.

    Paksa Restart Antigravity IDE?

    Pekerjaan yang belum disimpan akan hilang permanen. Paksa berhenti memakai /F hanya untuk PID executable IDE terverifikasi. Simpan pekerjaan atau batalkan.
