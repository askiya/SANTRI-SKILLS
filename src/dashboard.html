Reload Antigravity

Simpan pekerjaan terlebih dahulu. Dashboard tidak dapat memicu reload otomatis.

  1. Antigravity IDE: klik “…” di atas agent side panel → MCP Servers → Manage MCP Servers → klik tombol Refresh.
  2. Antigravity CLI: ketik /mcp di prompt panel lalu reload dari overlay.
  3. Fallback: Command Palette (Ctrl+Shift+P) → “Developer: Reload Window”.

MEMERIKSA
Target kustom aktif

Path tetap harus ditempel lengkap; browser tidak memberikan path absolut.

!Tutorial konfigurasi manualJika auto-deteksi tidak menemukan target
  1. Di Antigravity buka Settings → Customizations → Installed MCP Servers → Manage MCP Servers → View raw config.
  2. Lokasi global: ~/.gemini/config/mcp_config.json; workspace: .agents/mcp_config.json; beberapa build lama: ~/.gemini/antigravity/mcp_config.json.
  3. Root JSON harus memiliki objek mcpServers. Backup file sebelum mengedit.
{
  "mcpServers": {
    "santri-skills": {
      "command": "npx",
      "args": ["-y", "santriverse-skills", "mcp-serve"]
    }
  }
}

Peringatan: jaga JSON tetap valid dan jangan hapus server lain.
