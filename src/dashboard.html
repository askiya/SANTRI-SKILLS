Upload Skill ke Gemini
  1. Setujui aturan distribusi, pilih Skill, lalu unduh paket.
  2. Buka Gemini melalui ekstensi. Jika bantuan otomatis gagal, buka Settings → Skills.
  3. Pilih Upload, lalu ZIP atau folder dengan SKILL.md di root sesuai opsi Gemini.
  4. Periksa isi dan tekan Create/Upload terakhir sendiri.

Deteksi halaman bukan bukti Skill aktif. Status konfirmasi member dicatat terpisah.

Peringatan distribusi

Dilarang membagikan, menjual ulang, mengunggah ulang, atau memberikan Skills, file, package, prompt, maupun materi resmi Santriverse kepada orang lain. Jika pelanggaran terbukti, member dapat dikeluarkan dari grup dan komunitas serta kehilangan pembaruan akses Skills.

Salinan yang sudah diunduh dapat disalin secara teknis; peringatan bukan DRM.

    MEMERIKSA
    Target kustom aktif

    Path tetap harus ditempel lengkap; browser tidak memberikan path absolut.

    Global semua workspace: ~/.gemini/config/skills/<id>/SKILL.md dan ~/.gemini/config/mcp_config.json. Project saat ini: <project>/.agents/skills/<id>/SKILL.md dan <project>/.agents/mcp_config.json. Jangan gunakan folder builtin, plugin, runtime, atau cache.

    !Tutorial konfigurasi manualJika auto-deteksi tidak menemukan target
    1. Antigravity Settings → Customizations → Installed MCP Servers → Manage MCP Servers → View raw config.
    2. Root JSON wajib memiliki objek mcpServers. Backup sebelum edit.
    {
  "mcpServers": {
    "santri-skills": {
      "command": "npx",
      "args": ["-y", "santriverse-skills", "mcp-serve"]
    }
  }
}

    Peringatan: jaga JSON valid dan jangan hapus server lain.

    Restart Antigravity?

    Simpan pekerjaan terlebih dahulu. Antigravity akan diminta tutup secara graceful lalu dibuka lagi. Pekerjaan belum disimpan dapat hilang.

    Sumber berbeda dari target instalasi di atas. Scan maksimal 6 tingkat, 100 skills, 2000 entri, 8 MB. Hanya SKILL.md dan pendukung .md/.txt disalin; script, file tersembunyi, dan file sensitif dilewati.
